# Shajee Kitangoth — Personal Portfolio

A no-build, responsive portfolio page. Open `index.html` in a browser or publish the `shajee-portfolio` folder to a static web host.

The custom `logo.svg` monogram appears in the site header and as the browser tab icon.

## Photography

- **Add photographs** shows local image previews in the current browser session. They are not uploaded or saved. Persistent uploads need a backend or a storage provider.
- **Google Photos** accepts `photos.google.com` and `photos.app.goo.gl` album links. It opens the shared album in Google Photos rather than embedding it.

## Before publishing

Replace `hello@example.com` in `index.html` with the email address that should receive consultancy enquiries.
